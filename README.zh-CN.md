# Hidontknow Support

[English](README.md) | 简体中文

[Hidontknow 主题](https://github.com/hidontknow/obsidian-theme-hidontknow)的辅助插件。主题让实时预览和阅读模式看起来完全一样，但有几处差异来自 Obsidian 编辑器解析 Markdown 的方式，单靠 CSS 改不了。这个插件在实时预览里补上这些部分，源码模式不受影响。

| 内容 | 不装插件 | 装插件后 |
| --- | --- | --- |
| 引用里的列表 | 显示成普通的 `- `、`1. ` 文字 | 圆点、序号、可点击的复选框，间距和阅读模式相同，支持嵌套 |
| 列表里的代码块 | 外框从最左边开始，列表缩进算在代码里 | 整个代码块连同外框缩进到列表文字处 |
| 脚注引用 | 显示源码 `[^1]` | 上标 `[1]`，按首次引用的顺序编号，和阅读模式一样 |
| 文末的脚注定义 | 行内标签 | 和阅读模式一样的脚注区：分割线、序号、`↩︎` 返回链接 |
| `%%注释%%` | 灰色显示 | 隐藏；块注释连同后面的空行一起隐藏，段落间距和阅读模式相同 |
| 代码高亮 | CodeMirror 自己的高亮，切分方式和阅读模式不同 | 用阅读模式的 Prism 上色，颜色和样式逐字一致 |
| 列表符号 | `-`、`*`、`+` 显示一样；阅读模式把 `1)` 显示成 `1.` | `-` 实心圆点、`*` 空心圆、`+` 方块、`1)` 保留右括号，两种模式一致 |
| 会换行的任务项 | 换行后的行可能比首行文字靠左 1px | 换行后的行与首行文字完全对齐 |
| 有序列表编号 | `10.` 仍显示 10 | 两种模式按同一规则编号：从列表第一项的编号开始递增；紧跟在另一种列表（无序列表，或 `1.` 与 `1)` 互换）后面的有序列表从 1 重新开始 |

列表项换层级时（空项上按回车退出、Tab、Shift+Tab），符号会自动改成新层级那个列表的类型，后面的项跟着顺延编号，和这次编辑一起撤销。你自己手动输入的别的符号不会被改。

输入或修改有序列表项时，源码里的序号会自动改成显示的序号，文件内容和看到的一致。比如在 `2.` 后面输入 `7.` 会变成 `3.`，紧跟在无序列表后面的有序列表从 `1.` 开始。只改正在编辑的这个列表；撤销、打开文件和源码模式下都不改。

阅读模式里，插件还会按源码的空行留间距：两块之间没有空行就紧挨着，空两行就留两行高，列表项之间的空行（松散列表）也会保留，和编辑模式一样。

光标碰到这些内容时会显示原始 Markdown，方便编辑，和 Obsidian 处理自己的标记一样。

## 限制

- 写在正文中间的脚注定义留在原处，阅读模式会把它挪到文末。
- 行内脚注 `^[…]` 的编号正确，但它的内容不会出现在脚注区。
- 脚注区按源码顺序显示定义；阅读模式按首次引用排序，两者顺序相同时才一致。
- Prism 不认识的语言，代码块保留编辑器自己的高亮。
- 每次修改都会重新扫描整篇笔记，被修改的代码块会整块重新上色；特别长的笔记或几百行的代码块可能会变慢。

## 安装

上架社区插件之前，从最新的 [Release](https://github.com/hidontknow/obsidian-theme-hidontknow-support/releases) 下载 `main.js`、`manifest.json`、`styles.css`，放到 `<库>/.obsidian/plugins/hidontknow-support/`，再在「设置 → 第三方插件」里启用。

插件是按 Hidontknow 主题设计的，配合其他主题时间距可能对不上。

## 开发

源码在 `src/main.js`。运行 `npm ci`、`npm run build` 打包成 `main.js`。
